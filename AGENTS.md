# Project working preferences

- Keep responses clear, concise and to the point.
- Remind the user at good commit points.
- Say when an approach appears to be going in the wrong direction.
- Always include relevant inline pictures in research documentation, alongside
  the written interpretation. Prefer reference/render comparisons, reflection
  crops, normal/depth maps and plots from actual experiments. Reuse tracked assets.
- Caption figures with the scene, view and compared variants. Distinguish observed
  results from planned diagrams; preserve failures and avoid implying unmatched
  runs isolate a single cause. Never fabricate experimental images.
